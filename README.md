# pannello

Pagina statica (GitHub Pages) del pannello. **Nessun dato in chiaro in questo repository.**

- `main`: solo la pagina (`index.html`).
- `data`: un solo file `data.enc.json`, cifrato AES-256-GCM; chiave derivata (PBKDF2-SHA256) da un codice di accesso che non è nel repo.
Senza il codice la pagina non mostra nulla.
